# Планы

## Тулкит 1.3
- [x] **Меньше подсказок.** Переключатель в «Настройки → Общие → Вид». Убирает пояснения под пунктами во всём тулките и во всех аддонах. Тулкит отдаёт настройку аддонам через `host`, они реагируют сразу
- [x] **Суффикс файлов.** Общий в «Настройки → Общие → Имя готового файла»: `_wx` / `_trim` / свой (буквы, цифры, `-`, `_`, до 16 символов). В аддоне — «Как в настройках тулкита» или свой. У «Видео» появляется своя вкладка настроек
- [x] **Всё рядом с программой.** Установщик без прав администратора, в пользовательскую папку или куда выберешь. Данные в `…\wxwx toolkit\data`, если папка защищена от записи — запасной вариант `%LOCALAPPDATA%`. При первом запуске перенос старых данных, при удалении — вопрос, удалять ли данные
- [x] **Видео и Клипы** — поддержать подсказки и суффикс из тулкита
- [x] **Язык из установщика** — программа запускается на языке, выбранном при установке (portable — на языке Windows)

## Аддоны
- [x] **Видео** — сжатие видео и GIF
- [x] **Клипы** — нарезка записей из игр + сжатие
- [ ] **Сохранёнки / Saves** — видео и звук с YouTube, Instagram, TikTok (yt-dlp) · прототип готов
- [ ] **Обложки** — картинка и теги для MP3, M4A, FLAC · прототип готов
- [ ] **Фото** — сжатие и конвертация картинок (ImageMagick, WebP/AVIF) · прототип готов

## Общее для аддонов
- [ ] **Одна папка виджетов** (`addons/_shared/`): слайдер, чипы, сегменты, переключатели — вшивается в каждый аддон при сборке. Делаем вместе с «Сохранёнками», потом переводим «Видео» и «Клипы»
